# Privacy Notes

This scaffold runs local transformations only. It does not collect, store, transmit, enrich, or scrape personal data.

## Current Data Handling

- Inputs are supplied by the user inside Zapier or local examples.
- Outputs are generated synchronously from those inputs.
- No recipe makes network requests.
- No credentials, API keys, cookies, or tokens are needed.
- No contact enrichment or outreach automation is included.

## Recommended Zapier Practice

- Do not paste secrets into these Code by Zapier fields.
- Avoid sending sensitive customer notes, health information, payment data, or private account data into these recipes.
- Review each Zap history entry because Zapier may retain task inputs and outputs according to the workspace settings.

Before building or submitting a Zapier Platform app, AdPages should define hosted API privacy behavior, retention windows, authentication flows, tenant isolation, deletion handling, and support contacts.
