# Publish Blockers

This package is not ready for Zapier Marketplace submission.

## Blocking Items

- No hosted AdPages API exists for Zapier to call.
- No authentication model has been selected.
- No production privacy review has been completed.
- No support, incident, retry, or rate-limit contract exists.
- No Zapier Platform app manifest or integration tests exist.
- No marketplace copy, screenshots, or app-review responses have been prepared.

## Non-Goals For This MVP

- Network calls.
- Web scraping.
- Credential handling.
- Contact enrichment.
- Outreach automation.
- Marketplace readiness claims.

## Publishable Surface Today

The publishable surface today is documentation and dependency-free Code by Zapier resource snippets that users can paste into their own Zaps.
